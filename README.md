# Employee Application - CRUD Operations

A full-stack application built with Java Spring Boot backend, Angular frontend, and MySQL database.

## Features
- Create employee records
- Read/Display employee records
- Update employee records
- Delete employee records

## Technology Stack
- **Backend**: Java Spring Boot
- **Frontend**: Angular
- **Database**: MySQL
- **Build Tool**: Maven

## Prerequisites
- Java 11+
- Node.js 14+
- MySQL 5.7+
- Angular CLI

See individual README files in backend and frontend directories.
